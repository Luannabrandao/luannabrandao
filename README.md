### 📌 Projetos em destaque

- **[🍽️ Meu Pratinho](https://github.com/Luannabrandao/meu-pratinho)** — App web de segurança alimentar pediátrica: escaneia rótulos com IA (Gemini 1.5 Flash) para detectar alérgenos, migrando de OCR tradicional (que confundia ingredientes como "manteiga de cacau" com derivados de leite) para uma leitura contextual, com um motor de fallback local em regex para garantir segurança mesmo sem conexão. `React` `TypeScript` `Google Generative AI SDK`

- **[🤖 Automação de Extração de Relatórios](https://github.com/Luannabrandao/script-backup-python-playwright)** — Robô de RPA em Python/Playwright que automatiza a extração de relatórios cruzando módulo, ano e unidade de negócio, com otimização na ordem dos loops para reduzir recarregamentos do sistema e validação de DOM para evitar downloads de dados vazios. `Python` `Playwright` `RPA`

- **[🥑 Mercado Inteligente](https://github.com/Luannabrandao/mercado-inteligente)** — SPA em React para planejamento financeiro doméstico e combate ao desperdício de alimentos, com dashboard de gastos por categoria, alertas de despensa crítica e lista de compras organizada por setor do mercado. `React` `React Router` `Soft UI`
